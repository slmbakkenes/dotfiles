Home row mods

Hold a home row key for a modifier: A/; Cmd, S/L Opt, D/K Ctrl, F/J Shift. Only works with a key on the other hand: Cmd+C is hold ;, tap C.

Accents

Hold Enter, tap an accent on the number row, let go, then type the letter: ´ e = é, ¨ e = ë. Needs macOS input source ABC.

Caps Word

Hold both Shifts (F + J) to type the next word in CAPITALS, like MAX_SIZE. Space ends it.

LED colors

The board lights up in the layer's color: orange base, aqua symbols, blue navigation, purple numbers, red system.
